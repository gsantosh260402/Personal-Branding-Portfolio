# Personal Branding Portfolio

A modern, responsive personal portfolio website built to showcase my skills, projects, and professional profile.  
Designed with a clean UI, smooth animations, and a strong focus on personal branding and user experience.

---


## 🚀 Features

- Fully responsive design (Mobile, Tablet, Desktop)
- Clean and minimal UI for strong personal branding
- Smooth CSS animations and transitions
- Well-structured and reusable code
- Fast loading and optimized assets

---

## 🛠 Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)
- Git & GitHub
